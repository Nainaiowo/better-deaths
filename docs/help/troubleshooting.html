Troubleshooting

Common questions

No pull or death appeared

Confirm you were inside a duty, not PvP or the overworld, and that Options → Capture → Capture party is enabled. A completed pull is saved after combat ends or the duty resets.

I selected one minute, but an older pull shows less

The display choice cannot recreate history that was not captured. Pulls recorded before longer capture was added may only contain their original lead-up.

Replay is missing a marker, debuff, or mechanic drawing

Older pulls may lack newer replay fields. Supported fights have encounter-specific drawings; unsupported fights rely on general captured data and may be less complete. Record a new pull before treating it as a current capture bug.

Why do I see two HP bars with an arrow?

Part of that event arrived in a different snapshot, so Better Deaths cannot safely combine the before-hit and after-hit HP into one bar. The arrow points toward the after-hit state and follows your Newest or Oldest timeline order.

Party HP and Active Effects moved over the arena

Replay changes layout when the window no longer has enough side space. The two panels share rows over the arena until more horizontal room is available, then return to separate, vertically stacked panels beside it.

The arena or player position is slightly off

Replay and FFLogs positions are snapshots rather than video. Interpolation and missing samples can shift what you see. Use a recording or the original log when exact placement matters.

Open in Replay is unavailable

The replay needs a saved pull with replay detail. Finish the current pull first. Older pulls recorded before that detail was captured may not have enough information to open.

Name Redaction is on, but a saved file still has names

Name Redaction changes presentation. It does not rewrite every original name already stored in local pull files.

An FFLogs link is not analyzing

Use a complete report link or a link to a specific fight. The selected fight must be Dancing Mad (Ultimate), reach the supported mechanic, and be available to the WTF.DIG service.

The Analyzer says timing is estimated

The pull did not contain the preferred mechanic timing marker. Better Deaths aligned the view using nearby recorded fight data instead, so treat exact timing and positions with more caution.

The Death Widget is missing

Enable it under Widgets → Death Widget or toggle it with /bdwidget. The widget is separate from the main Better Deaths window.

Glossary

Terms used in Better Deaths

Fatal event
The captured hit or event associated with the KO.
Overkill
The amount by which the captured killing damage exceeded HP before the hit. Captured shield value is shown alongside it for context.
Lead-up
The captured timeline before a death.
Snapshot
A recorded state at a moment in time, such as HP, position, or active statuses.
Non-hit KO
A death without a normal captured damage hit, such as certain encounter failures or forced deaths.
Recorded mechanic data
The Analyzer found the mechanic's preferred captured timing information instead of estimating it from nearby fight events.
Target mitigation
An effect applied to the player receiving damage rather than a party-wide or enemy effect.
Expired mitigation
An effect that ended near the death but is not counted as active on the selected hit.
