Options

Control behavior and capture

Options changes what Better Deaths does. Customize changes how it looks.

GeneralShow scrollbars and choose how many completed pulls are kept locally.
Death PopupEnable, test, reset, and choose the persistence of the post-death recap button.
Privacy & ChatPost clickable death links, choose their local display channel, redact names on screen, or remove Better Deaths branding from chat posts. Death Link channels are local UI channels, not party or public chat.
Capture partyRecords party deaths, including your own character.
Capture othersAlso tracks non-party player characters visible to your client.
ClockUses 24-hour or 12-hour local time in recorded-pull descriptions.
Current Pull WidgetShow or hide it, set opacity and icon size, and choose Normal or Concise display.

Customize

Shape the review workspace

Choose how much review information is shown, how it is ordered, and how the plugin fits your UI.

Review LayoutFocused or Detailed, Newest or Oldest, and a 10-second, 30-second, or 1-minute lead-up.
AppearanceMain-window opacity, Review icon size with a live example, same-instance pull group colors, and dark or light themes.
Advanced colorsStarts from the selected built-in theme, then lets you replace individual UI, event, HP, shield, and status colors. It can be reset back to the selected theme.
Fun ModeAn opt-in presentation mode in the top-right header. It changes playful wording and exposes the Ligma echo-chat button, but recorded information and calculations stay unchanged.

Data & privacy

Know what is stored and shared

Saved locally

Configuration and recorded pulls stay on your computer. Pull files can include names, jobs, duty details, timing, positions, waymarks, HP, shields, events, actions, statuses, and mitigation context.

Storage is visible

Data shows the number of saved pulls, detail-file count, recorded-pull size, total plugin folder size, debug-file size, and the local folder path.

Name Redaction is visual

It protects screenshots and shared display. Existing local pull files may still contain the original captured names.

Chat sharing is optional

Death links are Dalamud chat payloads that help another Better Deaths user find a matching local recap. They are not web uploads.

FFLogs Analyzer is the network exception

When you choose the FFLogs source, the report code is sent to WTF.DIG's service so it can retrieve that report from FFLogs. Local Pull analysis does not use that lookup.

Feedback opens your browser

The feedback button asks for confirmation, then opens the Punish Discord invite. Better Deaths does not attach pull data to that link.
