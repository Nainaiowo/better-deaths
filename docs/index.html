One place for the pull you just played

Better Deaths connects death review, mitigation context, replay, and supported mechanic analysis so the useful parts of a pull stay together.

Death Review

See the fatal event, HP plus shields, mitigation context, expired effects, enemy HP, and up to one minute of lead-up data for each KO.

WTF.DIG Analyzer

Analyze supported Dancing Mad mechanics from an eligible Better Deaths pull or an FFLogs report link, with mechanic-specific diagrams and assignments.

Death Replay (Beta)

Play through captured positions, movement, markers, active effects, and supported mechanic shapes around a selected death.

What-if Mitigation

Select available mitigation and compare the projected damage against the recorded fatal hit before changing the next pull's plan.

Death Widget

Keep a compact current-pull death list open during progression, then open the latest recap directly when a closer review is needed.

Themes and Sharing

Match the plugin to your UI, redact names for screenshots, and share concise death information through optional in-game chat posts.

Captured data stays local

Better Deaths does not upload captured pulls. It has no telemetry, analytics, feedback endpoint, or hidden network reporting. When you choose FFLogs Link in WTF.DIG, only the report reference needed for that lookup is sent to the analyzer service.

Saved Locally

Recorded pulls stay on your machine so they remain available after wipes, resets, reloads, or plugin updates.

What Gets Saved

Saved review pulls can include names, jobs, duty details, death timing, HP, shields, events, actions, statuses, and mitigation context.

Name Redaction

Name Redaction helps with screenshots and shared display, but local saved pull files may still contain the original captured names.

See the pull from every angle

These are the same redacted views used throughout the Help Center.

Install Better Deaths

Add the custom plugin repository in Dalamud, then install Better Deaths from the plugin installer.

https://puni.sh/api/repository/nainai Open Repo JSON

Better Deaths only functions in duties. It does not capture overworld combat or PvP recaps.

Commands

/betterdeaths /bd /betterdeathswidget /bdwidget

Use these commands to open the main death recap window or toggle the death widget.
